# arXiv-2510.06451

## Data Generation
The datasets used in this project are produced by the Jupyter notebooks in /Data_Generation:
- `Lambda_Matrix_Generate.ipynb`
  Click run and one can obtain the Lambda-matrix used in the paper (form factors).
  This code realize two function:
  1. Define TBG BM model with tunable parameters include w0, w1 and twisted angle; This is in the first block of notebook;
  2. Define and obtain/store the particle-particle form when the pair momentum is at M-point; This is in the second block of notebook;
     One can search "TBG_Parameter" to find location of tunable model paramters; Explanation for parameters is in the notebook;
     One can search " Loc: COM_Tune" to find location of tunable pairing momentum; Explanation for parameters is in the notebook;
  
- `read_Lambda_Construct_triplet.ipynb`
  Click run and one can obtain the Lambda-matrix in the triplet channel at A-symmetry channel (sym=0).
  One can search "loc_sym" to find location to generate the other two E1, E2-channels (set syms=(0,1,2))
  
- `read_Lambda_Construct_singlet.ipynb`
  Click run and one can obtain the Lambda-matrix in the singlet channel at A-symmetry channel (sym=0).
  One can search "loc_sym" to find location to generate the other two E1, E2-channels (set syms=(0,1,2))

After singlet/triplet form factors are stored, run the code below to solve gap equations.

- `Solvegrand_singlet.ipynb`
  Used to obtain solutions to the gap equation in grand-canonical emsemble
  Current code solve A-symmetry channel (sym=0).
  One can set flat_dir = "lambda_singlet" to flat_dir = "lambda_triplet" to run triplet solutions.
  sym-channel, Temperature, subspace_dim (dimension of subspace), interaction strength are tunable parameters.

- `Solve_singlet.ipynb`
  Used to obtain solutions to the gap equation in canonical emsemble.
